Method, limits and reproduction
The episodes are the previously published seed-09 reference, dim and camera conditions. The same task and initial physics were recorded across those conditions. Selection predates these reviews. Each mode receives the same contact sheet, with the recorded facts added only in the second mode. Added facts change the prompt; the comparison does not isolate visual ability.
Qwen/Qwen3.8-27B-FP8 is fixed to revision 017b9c7af6b5689d5dd426a76e0bc077eb5ca20a. Generation uses seed 17, temperature 0.6 and at most 512 new tokens. The source bundle retains the protocol, hashes, raw outputs, runtime identity and every check. A model that repeats a supplied field has demonstrated record reading, not independent discovery.
robot-reel review-claims trace.json claims.json --output review.json
The offline checker compares outcome and action count, and checks whether cited frame labels exist. It does not verify that a cited image supports the explanation or authenticate the supplied trace.
